HOW TO USE THIS INSTALLER SOLUTION
===============================================================================

STEP 1: Choose Installation Method
──────────────────────────────────

Option A - SIMPLE (install.bat)
  ├─ Best for: Small deployments, internal use
  ├─ Files needed: install.bat + pos.exe + migrate.exe
  ├─ User runs: install.bat as Administrator
  ├─ Result: Application in C:\Program Files\POS System
  └─ Effort: Minimal

Option B - PROFESSIONAL (NSIS Installer)
  ├─ Best for: Enterprise, wider distribution
  ├─ Files needed: POS_Installer.nsi + pos.exe + migrate.exe
  ├─ You run: NSIS to build .exe installer
  ├─ Users run: POS_System_Installer_v1.0.exe
  ├─ Result: Professional installer package
  └─ Effort: Moderate (requires NSIS)

Option C - PORTABLE (USB/Portable)
  ├─ Best for: USB drives, demonstrations, temporary use
  ├─ Files needed: pos.exe + migrate.exe + data/ folder
  ├─ Users run: pos.exe directly
  ├─ Result: No system installation, runs from USB
  └─ Effort: Minimal

STEP 2: Prepare Distribution Package
─────────────────────────────────────

For Option A (Batch Installer):
  1. Create folder: C:\Delivery\POS_System_v1.0
  2. Copy: install.bat, pos.exe, migrate.exe
  3. Copy: README.txt, INSTALLATION_GUIDE.txt, REQUIREMENTS.txt
  4. Create ZIP: POS_System_v1.0.zip
  5. Done - ready to distribute

For Option B (NSIS Installer):
  1. Open NSIS Compiler
  2. File → Open → POS_Installer.nsi
  3. Click Compile (F11)
  4. Generates: POS_System_Installer_v1.0.exe
  5. Include: README.txt, INSTALLATION_GUIDE.txt, REQUIREMENTS.txt
  6. Done - ready to distribute .exe

For Option C (Portable):
  1. Create folder: POS_Portable_v1.0
  2. Copy: pos.exe, migrate.exe
  3. Create: data/ folder with empty CSV files
  4. Create ZIP: POS_Portable_v1.0.zip
  5. Done - ready to copy to USB or share

STEP 3: Distribute to Users
───────────────────────────

Distribution Methods:
  • Email (for ZIP files)
  • Website download
  • USB drive
  • Network share
  • Enterprise deployment tools (SCCM, Intune)

User Installation (Option A - Batch):
  1. User extracts ZIP
  2. User right-clicks install.bat → "Run as Administrator"
  3. User follows on-screen prompts
  4. Application installed in Program Files
  5. Launches from Start Menu

User Installation (Option B - NSIS):
  1. User runs POS_System_Installer_v1.0.exe
  2. Follows standard Windows installer wizard
  3. Chooses installation directory
  4. Clicks Install
  5. Launches from Start Menu

User Installation (Option C - Portable):
  1. User extracts to USB or any location
  2. User double-clicks pos.exe
  3. Application runs immediately
  4. Data saves in same folder
  5. No uninstall needed - just delete folder
