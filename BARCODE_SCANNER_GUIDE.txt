================================================================================
BARCODE SCANNER SETUP & USAGE GUIDE
POS System v1.0
================================================================================

===============================================================================
OVERVIEW
===============================================================================

The POS System includes integrated barcode scanner support for efficient
product entry during sales transactions. This guide explains setup and usage.

Features:
  • Multi-port support (COM1-COM9 serial ports, USB devices)
  • Auto-detection of connected barcode readers
  • Legacy and modern laser reader compatibility
  • Real-time data collection via background thread
  • No manual typing required for barcode input

===============================================================================
HARDWARE COMPATIBILITY
===============================================================================

COMPATIBLE SCANNER TYPES:
  ✓ Laser barcode readers (standard RS-232)
  ✓ USB barcode scanners (appear as virtual COM port)
  ✓ Wired and wireless (if connected via USB dongle)
  ✓ Old and new models supported

COMPATIBLE PROTOCOLS:
  ✓ RS-232 serial communication
  ✓ USB serial emulation (CDC)
  ✓ Standard baud rates: 9600 (default), 19200, 38400, 57600, 115200
  ✓ 8-bit data, 1 stop bit, no parity
  ✓ CR/LF line ending support

SCANNER PORT CONNECTIONS:
  • Classic COM ports (COM1 through COM9)
  • USB ports (detected and mapped to virtual COM port)
  • USB-to-serial adapters (supported)

TESTED MODELS:
  • Honeywell Hyperion series
  • Symbol/Zebra DS3000 series
  • Metrologic/Honeywell MS series
  • Generic laser barcode readers (9600, 19200 baud)
  • Datalogic Gryphon series

If your scanner is not listed, check manufacturer for RS-232 or USB support.

===============================================================================
PORT IDENTIFICATION
===============================================================================

FINDING YOUR SCANNER'S PORT:

Method 1: Windows Device Manager
  1. Open: Start Menu → Device Manager
  2. Expand: "Ports (COM & LPT)"
  3. Look for: COM port with "USB" or scanner brand name
  4. Right-click → Properties for baud rate info

Method 2: Auto-Detection (Easiest)
  1. Connect barcode scanner to computer
  2. In POS System Sales tab, click "Connect Scanner"
  3. Application auto-detects and connects
  4. Status will show "Connected" if successful

Method 3: Manual Port Testing
  1. Connect scanner
  2. Scan a test barcode
  3. Watch Device Manager for which COM port gets data
  4. Use that port in POS System

COMMON PORT NAMES:
  • COM1, COM2, COM3: Legacy serial ports (rare on modern computers)
  • COM4-COM9: Virtual USB ports (most common)
  • Check Device Manager for exact mapping

===============================================================================
INITIAL SETUP
===============================================================================

STEP 1: CONNECT HARDWARE

  Serial (DB-9) Cable:
    • Plug scanner into serial cable
    • Plug serial cable into COM port adapter (if needed)
    • Connect to computer's USB port or serial port

  USB Barcode Scanner:
    • Plug USB cable directly into computer USB port
    • Windows will auto-detect (driver usually built-in)
    • Appears as a virtual serial (COM) port

  Wireless Scanner (with USB dongle):
    • Plug USB dongle into computer
    • Turn on scanner
    • Follow scanner pairing instructions
    • Should appear as a COM port in Device Manager

STEP 2: VERIFY CONNECTION

  In Device Manager:
    1. Open Device Manager (Start → Device Manager)
    2. Expand "Ports (COM & LPT)"
    3. Your scanner should list a COM port
    4. Note the port number (e.g., COM3, COM5)
    5. Optionally right-click and check Properties for baud rate

STEP 3: CONFIGURE IN POS SYSTEM

  Method A: Automatic (Recommended)
    1. Launch POS System
    2. Go to Ventas (Sales) tab
    3. Click "Connect Scanner" button
    4. Status changes to "Connected"
    5. Start scanning products

  Method B: Manual Port Selection
    1. Launch POS System
    2. Go to Ventas (Sales) tab
    3. Look for Scanner Status indicator
    4. If auto-detect fails, click "Connect Scanner"
    5. Type port manually (COM3, COM5, etc.)
    6. Click "Connect"

STEP 4: TEST

  1. Focus on the Barcode input field (in Sales tab)
  2. Scan a product barcode
  3. Barcode should appear in input field
  4. Product code should be recognized
  5. ENTER key adds to transaction

===============================================================================
USAGE IN SALES MODULE
===============================================================================

NORMAL WORKFLOW:

  1. Start Sale:
     • Click Ventas (Sales) tab
     • Verify "Scanner Status: Connected"

  2. Scan Products:
     • Click in barcode input field
     • Use laser reader to scan product barcode
     • Barcode auto-appears and product is looked up
     • Quantity defaults to 1

  3. Adjust Quantity (if needed):
     • Press TAB to move to quantity field
     • Type quantity
     • Press ENTER (key feature) to add to transaction
     • Or use fractional quantity dialog

  4. Add More Items:
     • Click back in barcode field
     • Scan next product
     • Repeat until transaction complete

  5. Complete Sale:
     • Click "Finalizar" (Finalize) button
     • Transaction is recorded
     • New sale begins

KEYBOARD SHORTCUTS IN SALES:

  ENTER        Confirm barcode entry / add to transaction
  TAB          Move to quantity field
  Ctrl+N       New sale
  Escape       Cancel current transaction

===============================================================================
TROUBLESHOOTING
===============================================================================

ISSUE: "Scanner not detected"

  Solution 1: Check Physical Connection
    • Verify cable is properly connected
    • Try different USB port
    • Check Device Manager for COM port
    • Restart computer if needed

  Solution 2: Check Baud Rate
    • Right-click COM port in Device Manager
    • Select Properties → Port Settings
    • Verify baud rate (usually 9600)
    • Note baud rate and compare with scanner manual

  Solution 3: Manual Connection
    • Click "Connect Scanner" button
    • Manually select COM port and baud rate
    • Click Connect

  Solution 4: Update Drivers
    • Open Device Manager
    • Right-click scanner COM port
    • Select "Update driver"
    • Let Windows search for updates
    • Restart application

---

ISSUE: "Scanner connects but barcode not recognized"

  Solution 1: Check Barcode Format
    • Verify barcode is EAN-13, UPC, or Code128
    • Try scanning different product
    • Check scanner manual for supported formats

  Solution 2: Check Product in Database
    • Product barcode must exist in sistema
    • Go to Inventario tab to verify
    • Add product if missing
    • Re-scan to test

  Solution 3: Adjust Barcode Settings
    • Some scanners send extra characters (prefix/suffix)
    • Check scanner manual
    • May need to adjust scanner settings
    • Contact scanner manufacturer if needed

---

ISSUE: "Multiple incorrect barcodes per scan"

  Likely: Scanner sending line ending twice or multiple characters

  Solution:
    • Check scanner settings (may have duplicate line ending)
    • Test with manual keyboard input vs scanner
    • Verify baud rate matches
    • Try different port if available

---

ISSUE: "Scanner was working, now disconnected"

  Solution 1: Reconnect Hardware
    • Check USB cable or serial connector
    • Try different USB port
    • Restart computer
    • Click "Connect Scanner" button again

  Solution 2: Port Lost in Windows
    • Unplug USB device
    • Wait 10 seconds
    • Plug back in
    • Windows will reassign COM port
    • Click "Connect Scanner" to reconnect

  Solution 3: COM Port Configuration Changed
    • Other application may have locked COM port
    • Close other applications
    • Restart POS System
    • Try "Connect Scanner" again

---

TROUBLESHOOTING CHECKLIST:

  □ Hardware physically connected
  □ Scanner appears in Device Manager
  □ COM port is not in use by another application
  □ POS System has permission to access COM port
  □ Baud rate matches scanner settings
  □ Product barcode exists in database
  □ Barcode format is supported (EAN-13, UPC, Code128)
  □ Scanner line ending setting is correct (CR/LF)

===============================================================================
BATTERY SCANNERS & WIRELESS
===============================================================================

IF USING BATTERY-POWERED OR WIRELESS BARCODE READERS:

Wireless Scanner Setup:
  1. Charge scanner according to manufacturer instructions
  2. Plug USB dongle into computer (or pair via Bluetooth)
  3. Power on scanner
  4. Follow pairing instructions if required
  5. Scanner should appear as COM port in Device Manager

Battery Maintenance:
  • Keep scanner charged between uses
  • Charge overnight for daily use
  • Typical battery life: 6-12 hours
  • Keep charger included with scanner

Wireless Range:
  • Typical range: 30-50 feet from USB dongle
  • Obstacles may reduce range
  • Don't block antenna area during scanning

Data Loss Prevention:
  • Battery failure won't lose data (stored in scanner or computer)
  • POS System saves to CSV after transaction completes
  • Connect periodically to sync data

===============================================================================
ADVANCED SETTINGS
===============================================================================

BAUD RATE CONFIGURATION:

If auto-detection doesn't work, try manual baud rates:

  Standard (Most Common):
    • 9600 baud - Default for most barcode readers
    • 19200 baud - Some newer USB scanners

  High Speed (Less Common):
    • 38400 baud
    • 57600 baud
    • 115200 baud

How to Find Correct Baud Rate:
  1. Check scanner manual or datasheet
  2. Look for "Serial Configuration" or "Communications"
  3. Default is usually 9600
  4. Adjust in Windows Device Manager if needed

PORT BUFFER SETTINGS:

For heavy scanning volumes (100+ items/hour):
  • Windows manages COM port buffers automatically
  • System is optimized for standard retail use
  • Barcode queue handles fast scanning

If Missing Barcodes:
  • Unlikely with standard retail speed
  • Check scanner battery (wireless)
  • Verify port connection
  • Contact support if persists

===============================================================================
PERFORMANCE TIPS
===============================================================================

FOR FASTEST CHECKOUT:

1. Position Scanner Comfortably
   • Place scanner where easy to reach
   • Keep barcode positioning consistent
   • Stand/sit in ergonomic position

2. Use Standard Workflow
   • Scan → Press ENTER → Scan next
   • Avoid typing quantities manually
   • Use fractional quantity dialog only when needed

3. Keep Database Current
   • Regularly add/update products
   • Ensure all product barcodes are accurate
   • Check for duplicate barcodes

4. Maintenance
   • Keep scanner lens clean
   • Check cable for damage
   • Keep USB connection secure

5. System Health
   • Restart POS daily for refresh
   • Keep latest Windows updates
   • Avoid running multiple heavy applications

EXPECTED PERFORMANCE:
  • Barcode scan to entry: <1 second
  • Product lookup: <100ms
  • Add to transaction: <50ms
  • Complete transaction with 20 items: 1-2 minutes (including payment)
