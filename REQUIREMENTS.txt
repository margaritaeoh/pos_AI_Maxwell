3. FILE STRUCTURE & DATA FORMATS
===============================================================================

3.1 DATA FILES
  Location: /data/ directory
  - productos.csv: Product information (comma-separated)
  - usuarios.csv: User credentials (comma-separated)
  - ventas.txt: Sales transactions (text format)
  - reporte_inventario.csv: Inventory report data
  - reporte_ventas.csv: Sales report data

3.2 CONFIGURATION FILES
  Location: User data directory (via wxStandardPaths)
  - custom_theme.ini: Custom theme settings (R,G,B color format)

3.3 DATABASE FILES
  Location: LMDB database directory
  - LMDB environment with multiple named databases
  - Products database
  - Users database
  - Sales database
  - Index database
